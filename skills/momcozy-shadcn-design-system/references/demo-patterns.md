## 产品定位

Momcozy demo 不是购物 App，也不是单纯品牌官网。它面向智能母婴硬件 IoT、护理与养育内容、家庭环境健康、社区陪伴和服务支持。

生成 demo 时优先表达：

- 设备连接、设备状态、数据监测和智能提醒。
- 母婴护理、产后恢复、育儿指导和健康内容。
- 家庭环境健康设备的运行状态、报告和建议。
- 社区交流、经验分享、成长记录和长期陪伴。
- 产品能力解释、使用指导、服务支持和账户体系。

CTA 语言应围绕产品体验，而不是交易转化。优先使用“添加设备”、“查看报告”、“开始指导”、“继续记录”、“查看建议”、“联系支持”、“加入讨论”、“了解设备”等。

## 页面参考怎么用

用户提供的旧页面或现有页面可以作为设计语言参考，但不能覆盖当前 token。

参考页面用于提取：

- 页面节奏、信息密度和模块组合方式。
- 图片比例、设备展示方式和内容层级。
- 标题语气、说明文案长短和状态表达。
- 社区、内容、设备、服务等场景里的常见布局。
- Momcozy 品牌的温暖、清晰、可信赖的气质。

不要从参考页面继承：

- 旧 CSS 的具体颜色、字号、圆角、阴影和间距。
- 与当前 token 冲突的视觉值。
- 购物车、结账、强转化购买链路。
- 与智能母婴 IoT、护理、养育、社区无关的营销式版式。

| 场景 | 适合生成的 demo |

| 设备详情 | 实时数据、趋势图、模式切换、提醒设置、异常提示、维护建议 |
| 护理指导 | 泵奶/恢复/护理步骤、周期计划、提醒、记录和建议 |
| 内容教育 | 育儿知识、专题卡片、阅读进度、收藏、相关推荐 |
| 成长记录 | 宝宝数据、时间线、里程碑、家庭成员协作 |
| 家庭环境健康 | 清洗机、加湿器、净化器、雾化器、母婴冰箱的状态和报告 |

## 信息架构

生成 demo 时优先用清晰的产品体验结构：

1. 当前状态：设备、内容或社区对象现在处于什么状态。
2. 关键数据：用户最需要快速判断的指标。
3. 推荐动作：下一步可以做什么。
4. 解释与指导：为什么出现这个状态，如何处理。
5. 长期记录：趋势、历史、收藏、成长或社区反馈。

避免把首屏做成单纯营销 hero。除非用户明确要求品牌落地页，否则首屏应直接展示可操作的产品体验。

## 组件优先级

优先用 shadcn/ui primitives 组合出以下 Momcozy demo 组件：

- Button：产品线主按钮、二级按钮、禁用态、按下态。
- Card：设备卡、内容卡、社区帖子卡、状态报告卡。
- Badge：设备状态、内容标签、社区话题、提醒等级。
- Tabs：设备概览/记录/设置，内容分类，社区频道。
- Dialog / Sheet：添加设备、设置提醒、快速记录、确认操作。
- Form：设备命名、家庭成员、通知偏好、支持工单。
- Table / List：设备列表、历史记录、支持状态。
- Alert：异常状态、护理提醒、环境健康建议。

## Voice Log 模式

语音快速记录属于 `Mom` 场景，适合处理泵奶、喂养、睡眠、尿布和提醒等高频记录。生成此类 Demo 时使用以下结构：

1. 从日常记录卡片进入，不单独做营销首页。
2. 首次使用先展示价值说明、隐私同意和麦克风权限。
3. 录音中提供明确的监听状态、时间反馈、波形和可中止动作。
4. AI 结果必须先提供可检查、可编辑、可删除的结构化记录，再允许保存。
5. 异常值、缺失信息和时间冲突分别使用 Status token，不只依赖颜色表达。
6. 主动作使用 `Fills / Mom / Primary` 与 `Labels / Mom / Primary`，普通文字使用 `Colors / Text`。
7. Light/Dark Mode 通过语义 token 切换。UI 型 PNG（导航、栏位、文字卡片、图标底板）必须提供暗色资源，或在无法拆分时使用经过视觉校验的受控滤镜；照片、人物、产品和设备外框保持原始影像，不进行全局反色。
8. 可独立打开的静态 Demo 在页面右上角提供主题切换入口；被 React 或其他容器嵌入时隐藏内部入口，由外层统一控制，避免出现两个开关。
9. 同一工程包含多个 Demo 时统一放入 `public/demos/`，使用 `01-name/`、`02-name/` 的两位编号目录；提供一个状态目录页和稳定的预览路由，不把独立示例散落在 `public/` 根目录。

组件应服务于设备管理、内容指导和社区互动；不要默认围绕价格、库存、购买按钮或结账流程组织。

## 产品线映射

- `Mom`：泵奶、产后恢复、护理设备和妈妈健康设备。
- `Care`：安抚看护、婴儿监测、白噪音、摇椅、智能袜、AI 玩具。
- `Parenting`：养育工具、暖奶/调奶、尿布台体重秤、育儿内容和成长记录。
- `Family`：家庭环境健康设备，包括清洗机、加湿器、净化器、雾化器、母婴冰箱。
- `Grays`：全局中性色、文字、背景、边框和默认 shadcn/ui 基础主题。

如果页面跨多条产品线，以页面主任务决定主色；其他产品线色只用于标签、分类或局部强调。

## 不要做的事

- 不要把 Momcozy demo 默认做成购物 App。
- 不要默认生成购物车、结账、优惠券、价格比较或强促销模块。
- 不要把页面参考当作 token 来源。
- 不要为了丰富视觉而过度使用大面积品牌色。
- 不要把社区做成泛内容流；社区内容要围绕母婴、设备使用、护理经验和家庭陪伴。
